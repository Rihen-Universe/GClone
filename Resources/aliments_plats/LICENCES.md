# Aliments libres de droits, style à aplats (images des niveaux de FoodHunt)

Images SVG sans aucun dégradé, prises dans **Fluent Emoji de Microsoft**.

- Source : https://github.com/microsoft/fluentui-emoji (dossier `assets/<Nom>/Flat/`)
- Licence : **MIT**, https://github.com/microsoft/fluentui-emoji/blob/main/LICENSE
- Les fichiers sont copiés tels quels, seul le nom est simplifié (`red_apple_flat.svg` devient `red_apple.svg`).
- `FoodHunt/tools/embarquer_niveaux.py` en tire les grilles de cubes de `FoodHunt/src/Nk25DGrillesData.h`.
